## 5. 变更控制

| 规则 | 内容 |
|---|---|
| 范围变更 | 新增页面/功能必须写明：工时、是否推迟 M 门禁、是否影响性能预算；写进本文 §1 再动手。**删减功能属最高级别变更**：必须先改 00 篇 D7，再把对应 F-ID 从 [12 篇](12-feature-parity.md) §2 标为"不做"并记录理由，不得在执行中静默跳过 |
| Core 变更 | 一律先写 RFC（04 篇 §5 格式），批准后才改 `external/CKAN`，且单独提交、便于 rebase |
| 门禁不放行 | M2 门禁不通过不进 M3；宁可推迟，因为 M2 之后的一切都建立在"能正确装"上 |
| 决策变更 | 更新 00 篇 §4 的 ADR 表，记原因 |

## 6. Definition of Done（每个任务）

1. 代码进主干，CI 绿；
2. 有测试（VM/服务类：单测；集成类：TST-03 风格）；
3. 无 `TODO` 遗留在用户可见路径上；
4. 用户可见字符串已进 `.resx`；
5. 涉及 UI 的，深色主题下也验证过；
6. 涉及 Core 调用的，异常路径有人为触发过的证据（截图或日志）；
7. 对应的 F-ID（[12 篇](12-feature-parity.md) §2）已在 TST-05 矩阵里勾为"通过"，并附验收证据。
8. 涉及 E3 配置写入的，**已跑过 fixtures 往返黄金测试**（除目标行外逐字节不变），且写盘走 `IAdapterWriter` 唯一入口；
9. 涉及日志/诊断包/AI 调用的，**已跑过脱敏反向扫描**且零命中；涉及外发请求的，代码里不存在任何未经用户点击触发的发送路径（[14 篇](14-log-and-ai-debug.md) §5/§6）；
10. 涉及界面文案的，**字符串在 L1 或 `legacy-map.json` 里有一席之地**（无字面量）、`{loc:T}` 绑定可热刷新、且伪本地化下不截断（[16 篇](16-i18n.md) §4.3/§7.3）；
11. 涉及元数据译文的，**`h` 与 `i18n_tools` 交叉校验通过**、门禁 G2–G9 跑过、且英文词搜索结果集未被改变（[17 篇](17-mod-metadata-i18n.md) §10）。
12. 涉及资源释放的，**`metrics.jsonl` 五阶段读数齐全**、三档行为可复现、恢复路径无空白列表，且 KSP 装载时间差异在 ±3% 内（[18 篇](18-launch-resource-release.md) §10）；
13. 涉及安装/卸载/注册的，**普通账户全程无 UAC**、HKLM 零新增、卸载后用户数据仍在，且静默装/卸退出码为 0（[19 篇](19-windows-install-flow.md) §14）；
14. 涉及外观个性化的，三变体/强调色/材质/圆角/背景/密度/字号/动效八项都能即时生效并可恢复默认，且任何一种组合都不得突破滚动 p99 ≤16.7ms 与 WCAG AA 对比度（[20 篇](20-appearance-personalization.md) §14/§15）；
15. **提交前后跑过 `tools/verify-layout`**：不新增根目录条目、不提交产物/日志/大夹具、文档改动已登记 `docs/README.md` 索引、无本机绝对路径（[21 篇](21-repo-layout.md) §12）。
